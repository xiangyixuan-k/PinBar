- **图钉决定去留** — 常用项目常驻，其他图标进入收纳区。
- **悬停即可打开** — 不激活应用，移出面板后自动收回。
- **保留原有菜单** — 点击程序名称，展开原图标并尝试打开它的菜单。

## 安装

1. 下载 [PinBar.zip](https://github.com/xiangyixuan-k/PinBar/releases/download/v1.3.2/PinBar.zip)，解压后将 `PinBar.app` 放入“应用程序”。
2. 打开 PinBar，在“系统设置 → 隐私与安全性 → 辅助功能”中允许 PinBar。
3. 在菜单栏找到拼图图标，悬停或点击打开面板，用图钉选择常驻项目。

当前安装包适用于 Apple Silicon，要求 macOS 14 或更新版本；使用本地签名，未做 Apple 公证。如果 macOS 阻止首次打开，请先核对下载来源，再按“系统设置 → 隐私与安全性”的系统提示允许打开。辅助功能权限用于识别、移动和打开菜单栏图标，具体行为见[实现与限制](#实现与限制)。

发布页也提供 [Usage.txt](https://github.com/xiangyixuan-k/PinBar/releases/download/v1.3.2/Usage.txt) 使用说明。

## 使用

| 面板状态 | 含义与操作 |
| --- | --- |
| 蓝色图钉 | 项目常驻菜单栏 |
| 灰色图钉 | 项目已收起 |
| 点击程序名称 | 展开现有收纳区，并尝试打开原菜单 |
| 临时展开 | 显示原图标；点击“收起图标”恢复 |

- 鼠标停在拼图上约 160 毫秒，面板浮现；移出约 340 毫秒后淡出。
- 悬停不激活应用；点击面板后保持打开，按 Esc 或关闭按钮收回。
- 蓝色图钉代表常驻，灰色代表已收起。点击程序名称展开现有收纳区并尝试打开原菜单。
- 临时展开显示原图标，再点击“收起图标”恢复。设置中可关闭悬停打开、启用开机启动。
- 系统项目在列表中使用苹果标志。退出后，收起的图标恢复显示。

## v1.3.2 修复

- 取消逐段拖动路径。显式点击图钉时执行一次短暂的系统换位；启动、悬停及打开项目不执行逐项换位。
- 处理位于菜单栏中间的项目，不再依赖移动本程序分隔线来跨过相邻图标。
- 换位后等待实际窗口位置稳定，再提交图钉状态，避免图标仍显示却提前标为“已收起”。
- 单独保存分隔线位置，避免 AppKit 移除状态项时异步清空位置偏好。
- 发布版本采用固定本地代码签名，更新保持同一身份，减少重复授权。

## 实现与限制

SwiftUI + AppKit 原生材质、短距离浮现和淡出；尊重系统“减弱动态效果”。悬停仅读取鼠标位置，不发送输入事件，并为图标到面板的间隙保留通道。

macOS 没有供其他应用逐项隐藏状态项的公开接口。点击图钉仍需模拟系统的 ⌘ 换位操作，可能短暂移动指针。期间短暂观察实际鼠标输入，检测到操作则停止后续换位，并恢复最近记录的位置；观察器结束后移除，不保存输入。不能保证所有程序接受自动换位。失败时保留原选择并提示手动处理：临时展开，按住 ⌘ 将原图标移到分隔线左侧（收纳）或右侧（常驻），再刷新。

系统时钟、控制中心等保留项目不能收起。刘海、屏幕宽度、多屏和全屏布局可能限制原图标的可见范围；当前主要验证主屏。启动时保留已有顺序，不自动逐项重排，仍在菜单栏的已选收起项目会标明失败。

无网络请求、后台服务或第三方运行依赖。适用于 Apple Silicon、macOS 14+，未做 Apple 公证。

如果图标没有按预期收起，先检查辅助功能授权，再尝试上面的手动换位方法。反馈问题时请注明应用版本、macOS 版本、机型、屏幕布局及对应程序；分享诊断信息前移除个人应用名称和其他私人信息。

## 构建和检查

需要安装 Xcode Command Line Tools。克隆仓库后运行下列命令构建，默认不依赖私有签名状态；`--diagnose` 提供只读菜单栏诊断。

```sh
./build.sh ./build/PinBar.app
```

构建脚本会读取 `PINBAR_SIGNING_STATE_PATH` 指定的签名状态，或查找相对的 `work/pinbar-signing/state.json`；缺少状态时回退到临时签名。发布构建所用固定签名保存在隔离钥匙串，不修改系统证书信任或默认钥匙串；私有签名状态只在 `work/` 中，不随交付包分发。自行构建的签名身份可能与下载版本不同，需要重新检查辅助功能授权。

```sh
swiftc -parse-as-library Sources/LayoutRules.swift Sources/HoverRules.swift Tests/LayoutRegression.swift -o /tmp/pinbar-regression
/tmp/pinbar-regression
```
